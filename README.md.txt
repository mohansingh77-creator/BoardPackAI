# BoardPackAI

AI-Powered Executive Reporting & Board Pack Generation

## Overview

BoardPackAI transforms raw financial data into executive-ready board reports.

The solution automates:

* Budget vs Actual Analysis
* Variance Analysis
* KPI Dashboard
* EBITDA Reporting
* CFO Copilot
* AI Commentary
* Board Pack PowerPoint Generation

## Features

### KPI Dashboard

* Budget
* Actual
* Variance
* EBITDA

### Variance Analysis

Automatic variance calculations and highlights.

### CFO Copilot

Ask finance questions such as:

* What is EBITDA?
* Largest variance?
* Highest expense?

### AI Commentary

Generates:

* Executive Summary
* Key Variances
* Risks
* Opportunities
* Recommendations

### PowerPoint Generation

Creates board-ready PPT reports automatically.

## Technology Stack

* Python
* Streamlit
* Pandas
* Matplotlib
* Python-PPTX
* Google Gemini

## Installation

pip install -r requirements.txt

streamlit run app.py

BoardPackAI reduces manual reporting effort and accelerates executive decision-making.
